## Scientific architecture found
MESIA distinguishes wave discovery, protocol identification, usable agriculture sensing and scientific inference; receiver/antenna capability manifests and a coverage graph represent what is *observable*, including explicit gaps. `CoverageTuple` includes optional `spatial_position_wgs84`; the map should display those **only when present and qualified**, not position RF emitters from arbitrary illustrative graphics.
CoverageEngine evaluates receiver health and frequency ranges; observability is multidimensional (time, frequency, geometry, polarization). Scientific authority remains bounded by receiver geometry/calibration epochs and ASMAE evidence acceptance.

## Geospatial semantics
Physical receiver is a point; antenna direction a ray with uncertainty; *demonstrated* coverage a region with coverage outcome; a spectrum observation is receiver-linked event but not a map-wide agricultural measurement; a controlled plot trial is its registered polygon; a hypothetical RF propagation output is a simulation raster/geometry visibly watermarked. Coverage unknown -> do not imply continuous monitoring.
## Cross-workspace
Selecting receiver on map opens health, calibrated antenna and frequency windows. Choosing an experiment connects receiver locations, controlled source positions, plot zones, sensor references and ASMAE target hypotheses; after execution, compare measured observations, model expectations and held-out results at the same event timestamp. Experimental data never mutates canonical state absent admission.
## Required gates
No default satellite/mast count when unavailable; explicit `UNKNOWN` coverage; time/geometry epoch parity; simulation and actual capture visually distinct; real physical experiment completion requires instrument and raw logger receipts.
