## 2. Technical Analysis & Current Deficiencies

### The Scope Ambiguity
Currently, `run_orchestrator` branches based on `inputs.intent`:
- If `intent == "DIAGNOSIS"`: returns after Layer 3 (`l3_res`).
- If `intent == "DECISION"`: returns after Layer 6 (`l6_res`).
- If `intent == "NUTRIENT"`: returns after Layer 5 (`l5_res`).
- If `intent == "PLANNING"`: runs L1, L5, L7.
- If `intent == "FULL"`: runs L1 through L10.

#### Problems:
1. **False Completion Claims:** API consumers receiving a 200 OK often assume all 10 layers ran and that the system validated nutrient leaching and actions.
2. **Dual Ownership of Actions:** Layer 3 Decision produces an `ExecutionPlan` (`plan_l3`), Layer 4 produces a plan, Layer 5 produces a plan, and Layer 8 produces `List[ActionCard]`. It is undefined which layer is the ultimate legal owner of an agronomic spray or fertilizer prescription.
3. **Dual Ownership of Water:** Layer 3 Decision, Layer 3 Water, and Layer 4 Nutrients each own or calculate independent water balances.

## 3. Implementation Plan

### Step 1: Formalize Supported Execution Profiles
Define immutable profiles in `services/agribrain/orchestrator_v2/schema.py`:
```python
class ExecutionProfile(str, Enum):
    DIAGNOSIS_ONLY = "DIAGNOSIS_ONLY"       # L0.5 -> L1 -> L2 -> L3_DECISION
    HYDROLOGY_WATER = "HYDROLOGY_WATER"     # L0.5 -> L1 -> L2 -> L3_WATER
    NUTRIENT_BUDGET = "NUTRIENT_BUDGET"     # L0.5 -> L1 -> L2 -> L3_WATER -> L4
    PLANNING_STRATEGIC = "PLANNING_STRATEGIC"# L0.5 -> L1 -> L5 -> L7
    FULL_OPERATIONAL = "FULL_OPERATIONAL"   # L0.5 -> L1 -> L2 -> L3_WATER -> L3_DECISION -> L4 -> L5 -> L6 -> L7 -> L8 -> L10 -> L9
```

### Step 2: Declare Explicit State Ownership Matrix
Define single authoritative ownership in `services/agribrain/scientific_contracts/authority.py`:
| State Variable / Artifact | Sole Authoritative Owner | Non-Authoritative Consumers |
|:---|:---|:---|
| Soil Moisture & Layer Fluxes | **Layer 3 Water** | L4 Nutrients, L8 Prescriptions, L10 Surfaces |
| Agronomic Urgency & Stress Class | **Layer 3 Decision** | L8 Prescriptive Ranking, L9 Explanations |
| Crop Phenology & Biomass Derivative | **Layer 2 Vegetation** | L3 Water, L4 Nutrients, L7 Planning, L8 Scheduler |
| Nutrient Balance & N Leaching | **Layer 4 Nutrients** | L8 Action Cards, L9 Explanations |
| Biotic Disease / Pest Threat | **Layer 5 Biological Risk**| L7 Planning, L8 Prescriptions |
| Prescriptive Action Authorization | **Layer 8 Prescriptions**| Frontend Execution Dispatcher |
| Long-term Season Crop Rotation | **Layer 7 Planning** | Agronomist Strategic Review |
| Radio Environment Anomaly | **MESIA (Research Only)**| Contained proposals; 0 state authority |

### Step 3: Publish Run Execution Receipt
Every orchestrator response must emit a structured `ExecutionReceipt`:
```python
@dataclass(frozen=True)
class ExecutionReceipt:
    run_id: str
    profile: ExecutionProfile
    requested_layers: List[str]
    executed_layers: List[str]
    skipped_layers: List[str]
    failed_layers: List[str]
    degraded_layers: List[str]
    terminal_status: str  # "COMPLETE", "PARTIAL_DEGRADED", "FAILED"
```
