## 2. Technical Analysis & Current Deficiencies

### The Risk of Data Leakage & Unverified Model Updates
When deploying machine-learned parameter updates (e.g. neural evapotranspiration estimators or learned crop phenology curves):
- **Temporal Leakage:** Models often inadvertently train on future observations (e.g. using Savitzky-Golay smoothed NDVI values that look forward 10 days).
- **Synthetic Contamination:** Training on outputs generated by an earlier heuristic model causes the learned model to memorize the heuristic's errors rather than learning ground truth.
- **Uncontrolled Deployment:** Without a formal model registry, new neural weights or coefficients cannot be deterministically audited or rolled back.

---

## 3. Implementation Plan

### Step 1: Establish Strict Temporal & Spatial Split Datasets
In `services/agribrain/omega/evaluation/datasets.py`:
- Enforce strict causal masking:
  $$\mathcal{D}_{\text{train}} = \{(\mathbf{x}_t, \mathbf{y}_t) \mid t \le T_{\text{cutoff}}\}$$
  $$\mathcal{D}_{\text{test}} = \{(\mathbf{x}_t, \mathbf{y}_t) \mid t > T_{\text{cutoff}}\}$$
- Never use interpolated or smoothed values that incorporate post-$T_{\text{cutoff}}$ data points.
- Implement spatial holdouts (testing on geographically separate farm plots with different soil associations).

### Step 2: Implement the AgriBrain Model Registry
In `services/agribrain/model_registry/`:
```python
@dataclass(frozen=True)
class ModelCandidateRecord:
    model_id: str
    target_subsystem: str       # e.g. "layer3_water.evapotranspiration"
    version: str                # SemVer e.g. "2.1.0-candidate.3"
    training_data_manifest: str # SHA-256 hash of training dataset
    architecture_summary: str
    evaluation_metrics: Dict[str, float] # RMSE, MAE, CRPS, Bias
    baseline_comparison: Dict[str, float] # Improvement over standard FAO-56
    status: str                 # "CANDIDATE", "BENCHMARKED", "REJECTED", "STAGED"
    created_at: datetime
```

### Step 3: Offline Backtesting & Benchmark Comparison
Before any candidate model can be considered for staging:
- Run backtesting against the 7 frozen baselines (Task P00.2) and multi-year historical field data.
- Enforce that the candidate model:
  1. Achieves statistically significant lower error than standard physical baselines.
  2. Does not violate conservation of mass or energy on any step.
  3. Maintains well-calibrated prediction intervals (empirical $90\%$ confidence band contains $88\% - 92\%$ of ground truth points).
