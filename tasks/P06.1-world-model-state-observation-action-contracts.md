## 2. Technical Analysis & Current Deficiencies

### The Storage vs Dynamics Confusion
Currently, `services/agribrain/world_model/` implements `canonical_worldline.py`, which is an append-only JSON event store that logs plot events with hash identity.
*However, an event log is NOT a world model.*
A true Agronomical World Model requires formal mathematical contracts defining:
1. **State Space $\mathcal{S}$:** Physical, biological, and latent variables with explicit units and depth bounds.
2. **Action Space $\mathcal{A}$:** Differentiating proposed, scheduled, completed, and actually exposed farm actions.
3. **Disturbance Space $\mathcal{W}$:** Meteorological, hydrological, and pest boundary conditions.
4. **Observation Space $\mathcal{O}$:** Satellite radiances, probe millivolts, RF attenuation, and scouting reports.
5. **Transition Function:** $\mathbf{s}_{t+1} = f(\mathbf{s}_t, \mathbf{a}_t, \mathbf{w}_t; \boldsymbol{\theta}) + \boldsymbol{\epsilon}_t$ governed by mass and energy conservation.

```python
@dataclass(frozen=True)
class AgronomicalStateVector:
    plot_id: str
    timestamp: datetime
    # Soil Hydrology (5 discrete strata)
    soil_vwc_profile: List[float]               # [m3/m3] for layers 0-10, 10-20, 20-40, 40-60, 60-100 cm

    # Soil Nutrients
    mineral_n_topsoil_kg_ha: float              # [kg N/ha]
    mineral_n_subsoil_kg_ha: float              # [kg N/ha]
    # Latent Health / Pathogen Pressure
    foliar_pathogen_latent_spore_load: float    # [0, 1] normalized
    # State Covariance Matrix
    state_covariance: List[List[float]]
```

### Step 2: Formalize Action State Lifecycle
In `services/agribrain/world_model/contracts/action.py`:
A farm action transitions through 4 distinct phases on the worldline:
1. `PROPOSED`: Emitted by Layer 8 prescriptive optimization.
2. `SCHEDULED`: Bound to an approved weather window by the scheduler.
3. `COMPLETED`: Farmer / sprayer marks task done in telemetry.
4. `EXPOSED`: Agronomically verified exposure taking into account spray rain wash-off or fertilizer volatilization.
