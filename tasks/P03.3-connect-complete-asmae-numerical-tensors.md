## 2. Technical Analysis & Current Deficiencies

### 2.1 The Tensor Dimension Disconnect
MESIA projects opportunistic RF sensitivity zones as 2D spatial sensitivity kernels (Fresnel reflection zones, chord intersection ellipses) onto the parcel boundary:
- ASMAE expects spatial observations as standardized $H \times W$ float32 rasters on the 1m geodetic pixel lattice.
- *The Gap:* In `layer05_asmae/adapters/mesia_adapter.py`, RF proposals are serialized as flat single-value scalar floats. The spatial kernel weights $\mathbf{K}(x, y)$ are discarded, reducing spatially resolved radio tomography to a single coarse field-average number.

---

## 3. Implementation Plan

### Step 1: Export Normalized 2D Sensitivity Kernel Tensors
In `services/agribrain/mesia/lanes/spatial_projection.py`:
- Rasterize bistatic Fresnel ellipses onto the parcel grid:
  $$K_{i}(x, y) = \exp\left( - \frac{(x - x_0)^2}{2\sigma_x^2} - \frac{(y - y_0)^2}{2\sigma_y^2} \right)$$
- Emit serialized 2D numpy arrays encoded via base64 or flat arrays with explicit grid dimensions.

### Step 2: Implement Spatial ASMAE Tensor Ingestion
In `services/agribrain/layer05_asmae/adapters/mesia_adapter.py`:
- Ingest the 2D kernel raster into ASMAE's spatial Kalman filter.
- Update the belief grid $\mathbf{x}_{\text{grid}}[x, y]$ weighted by local sensitivity:
  $$\mathbf{x}_{\text{post}}[x, y] = \mathbf{x}_{\text{prior}}[x, y] + K_i(x, y) \cdot \mathbf{K}_{\text{gain}} \cdot \nu_i$$
