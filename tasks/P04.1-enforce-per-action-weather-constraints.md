## 2. Technical Analysis & Current Deficiencies

### 2.1 The Unconstrained Execution Window Flaw
In `layer8_prescriptive/scheduler.py`:
- Prescriptions generate action schedules (e.g. fungicide spraying, foliar herbicide, granular fertilization).
- *The Flaw:* Weather windowing only checks for extreme freezing temperatures ($T < 0^\circ\text{C}$).
- **Missing Environmental Invariants:**
  1. **Wind Spray Drift:** Pesticide/herbicide spraying is scheduled even when forecast wind speed exceeds $15\text{ km/h}$ (legal spray drift limit), risking off-target crop destruction and environmental toxicity.
  2. **Rain Wash-off:** Foliar contact fungicides are scheduled immediately before heavy rain events ($>10\text{ mm}$ within 6 hours), washing expensive chemicals into watercourses.
  3. **Fertilizer Runoff:** High-dose granular urea is scheduled during storm warnings, leading to massive surface runoff and water contamination.

## 3. Implementation Plan

In `services/agribrain/layer8_prescriptive/scheduler.py`:

    max_gust_speed_kmh: float

    max_temp_c: float
    max_rain_next_6h_mm: float
    max_rain_next_24h_mm: float
    min_leaf_drying_hours: float

ACTION_WEATHER_LIMITS: Dict[str, ActionWeatherConstraints] = {

### Step 2: Implement Weather Window Validator
Before scheduling an action window:
- Query Layer 0 microclimate forecast for parcel geodetic coordinates.
- Evaluate constraints across candidate 4-hour execution blocks.
- If no valid window exists within 72 hours, mark action `DEFERRED_UNFAVORABLE_WEATHER` with clear explanation.
