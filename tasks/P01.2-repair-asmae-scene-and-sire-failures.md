## 3. Implementation Plan

### Step 1: Fix External Scene Loader Resolution Resolution
In `services/agribrain/layer05_asmae/geometry/external_scene_loader.py`:
```python
res_m = record.get("resolution_m")
if res_m is None and transform and len(transform) >= 2:
    res_m = abs(float(transform[1]))  # pixel width from affine matrix
if res_m is None:
    res_m = 10.0  # default Sentinel-equivalent baseline
```
Pass `resolution_m=res_m` in metadata dictionary.
