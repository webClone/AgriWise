## 2. Technical Analysis & Current Deficiencies

### 2.1 Manifest-Time vs Use-Time Authority Gap
In `mesia/assimilation/capability_governance.py`:
- `CapabilityAuthorityRecord` certifies that a receiver hardware bundle passed laboratory qualification.
- *The Gap:* This qualification is checked once when the sensor manifest is created, but **not re-verified when a specific observation is assimilated into AgriBrain**.
- If antenna displacement occurred ($\Delta\mathbf{r} > 1\text{ cm}$), calibration expired ($t > t_{\text{calib}} + 24\text{h}$), or software version drifted, the system continues to process observations under historical manifest authority, violating **Principle P-09** and **P-10**.

## 3. Implementation Plan

### Step 1: Implement Dynamic Use-Time Qualification Check
In `services/agribrain/mesia/assimilation/capability_governance.py`:
```python
def verify_use_time_authority(
    record: CapabilityAuthorityRecord,
    observation_time: datetime,
    current_geometry_epoch: GeometryEpoch,
    current_calibration_state: CalibrationState,
) -> Tuple[bool, Optional[str]]:
    # 1. Temporal expiry check
    if observation_time > record.valid_until:
        return False, "EXPIRED_AUTHORITY_RECORD"
    # 2. Geometric alignment check (Principle P-06)
    if record.geometry_epoch_id != current_geometry_epoch.epoch_id:
        return False, "GEOMETRY_EPOCH_MISMATCH"
    # 3. Calibration validity check
    if not current_calibration_state.is_valid:
        return False, "CALIBRATION_INVALIDATED"
    return True, None
```

### Step 2: Integrate into Layer 0 Evidence Spine
In `services/agribrain/mesia/integration.py`:
- Before admitting any `RadioObservationPacket` into Layer 0:
  - Verify signature and content hash against `native_data_hash`.
  - Execute `verify_use_time_authority()`.
  - If rejected, emit a `RevocationEvent` and mark packet status as `QUARANTINED`.
