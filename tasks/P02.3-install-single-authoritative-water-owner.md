## 2. Technical Analysis & Current Deficiencies

### 2.1 The Two-Water-Engines Schism
AgriBrain possesses two completely decoupled hydrology implementations:
1. **`layer3_water`**: Advanced multi-layer Richards/Campbell hydraulic conductivity, FAO-56 dual $K_c$, probe assimilation, and MPC irrigation optimization.
   - *Current Reality:* In `orchestrator_v2/registry.py`, `LayerId.L3` routes exclusively to `layer3_decision` (weed/pest/diagnostic urgency). `layer3_water` is completely orphaned with **zero production callers**!
2. **`layer4_nutrients` Private Bucket Hydrology**: Because it never receives water state from L3, `layer4_nutrients/runner.py` runs its own private `SoilWaterBalanceEngine`, ignoring all multi-layer hydraulic physics and probe assimilations.

---

## 3. Implementation Plan

### Step 1: Split Layer 3 in Orchestrator Registry
In `services/agribrain/orchestrator_v2/schema.py` and `registry.py`:
- Introduce distinct IDs:
  - `LayerId.L3_WATER`: Computes physical water state, fluxes, and soil moisture strata.
  - `LayerId.L3_DECISION`: Diagnoses operational stress, pests, weeds, and urgency.
- Wire `run_layer3_water` as the authoritative predecessor to both `L3_DECISION` and `L4_NUTRIENTS`.

### Step 2: Formalize `HydrologyStateReceipt` Contract
In `services/agribrain/scientific_contracts/hydrology.py`:
```python
@dataclass(frozen=True)
class HydrologyStateReceipt:
    plot_id: str
    timestamp: datetime
    root_zone_vwc_pct: float
    depletion_fraction_p: float
    stress_factor_ks: float
    deep_percolation_mm: float
    actual_transpiration_mm: float
    actual_evaporation_mm: float
    is_authoritative: bool = True
```

### Step 3: Refactor Layer 4 to Consume `HydrologyStateReceipt`
In `services/agribrain/layer4_nutrients/runner.py`:
- Consume `l3_water_receipt = l3_water_res.output.hydrology_receipt`.
- Use `deep_percolation_mm` directly for nitrate leaching calculations.
- Demote private `SoilWaterBalanceEngine` to legacy fallback with an explicit `DEGRADED_UNAUTHORITATIVE_HYDROLOGY` warning.
