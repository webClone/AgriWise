## 2. Technical Analysis & Current Deficiencies

### The Self-Confirming Loop Hazard
Omega is designed as AgriBrain's autonomous meta-learning and hypothesis generation engine.
If an agent like Omega is permitted to adjust model parameters or recommend actions without rigorous separation:
- It can fall into a **self-confirming feedback loop**: an incorrect model predicts that a field needs less nitrogen, applies less nitrogen, observes lower vegetative vigor, and interprets the lower vigor as confirmation that the crop has lower nutrient demand.
- True learning requires comparing **prior predictions** against **independent future observations** and quantifying **predictive surprise** (epistemic residual) under controlled conditions.

## 3. Implementation Plan

### Step 1: Implement Immutable Predictive Forecast Archiving
In `services/agribrain/world_model/forecast_archive.py`:
- Whenever a production run makes a forecast (e.g. 7-day soil moisture depletion or 14-day vegetative trajectory), freeze and archive the forecast record *before* future observations arrive:
```python
@dataclass(frozen=True)
class ArchivedStateForecast:
    forecast_id: str
    plot_id: str
    issued_at: datetime
    horizon_days: int
    model_version: str
    forecasted_trajectories: Dict[str, List[float]]  # variable -> values
    forecasted_uncertainty: Dict[str, List[float]]   # variable -> sigma
```

### Step 2: Build the Epistemic Surprise Evaluator
In `services/agribrain/omega/surprise_evaluator.py`:
- When fresh observations $\mathbf{y}_t$ arrive, compute normalized predictive surprise:
  $$\text{Surprise}_t = \frac{|\mathbf{y}_t - \hat{\mathbf{x}}_{t|t-1}|}{\sqrt{\sigma^2_{\text{forecast}} + \sigma^2_{\text{sensor}}}}$$
- Classify the surprise into four mutually exclusive categories:
  1. `SENSOR_ANOMALY`: Rapid transient spike contradicted by neighboring sensors.
  2. `MISSING_DISTURBANCE`: Unreported irrigation event or localized heavy shower.
  3. `DOMAIN_SHIFT`: Extreme weather event exceeding model calibration envelope.
  4. `STRUCTURAL_MODEL_MISMATCH`: Genuine candidate for hypothesis generation and learning.

### Step 3: Emit Read-Only Experiment Proposals
In `services/agribrain/omega/proposals.py`:
- Omega generates structured `ExperimentProposal` records:
  - Documenting which versioned prediction was contradicted.
  - Proposing competing physical hypotheses (e.g. "Root depth in Zone 2 is $40\text{cm}$, not $70\text{cm}$ due to hardpan compaction").
  - Calculating expected information gain ($\text{EIG}$) of targeted scouting or soil core sampling.
- **Strict Invariant:** An `ExperimentProposal` is completely read-only. It has **zero authority** to modify production model weights, alter live state, or dispatch autonomous farm machinery.
