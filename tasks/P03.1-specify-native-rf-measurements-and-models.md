## 2. Technical Analysis & Current Deficiencies

### 2.1 Conflation of Statistical Likelihood Score with Physical Soil Moisture
In `mesia/behaviour/likelihood_engine.py` and `mesia/assimilation/asmae_operator.py`:
- `likelihood_val` is computed as a dimensionless Gaussian PDF probability ($p \in [0.01, 1.00]$).
- In `asmae_operator.py` line 67:
  ```python
  measured_vwc = likelihood.likelihood_value if likelihood.likelihood_value is not None else prior_state_vwc
  innovation = measured_vwc - prior_state_vwc
  ```
- If a signal has high confidence ($p = 1.0$), `measured_vwc` becomes $1.000\text{ m}^3/\text{m}^3$ (100% water!).
- Natural saturation of soil is $\approx 0.40 - 0.50$. Setting $\text{VWC} = 1.0$ creates an artificial $+0.80\text{ m}^3/\text{m}^3$ deluge innovation.

## 3. Implementation Plan

### Step 1: Formalize Physical Radio Observation Operator $\mathcal{H}_{\text{RF}}(\mathbf{x})$
Define explicit observation forward models that map physical soil permittivity $\varepsilon_r$ and moisture $\theta_v$ to expected RF observables $y$:
1. **Terrestrial UHF Ground Wave Penetration (470–700 MHz):**
   $$y_{\text{refl}} = \left| \frac{\sin\psi - \sqrt{\varepsilon_r(\theta_v) - \cos^2\psi}}{\sin\psi + \sqrt{\varepsilon_r(\theta_v) - \cos^2\psi}} \right|^2$$
2. **Cellular Downlink Forward Scatter Attenuation:**
   $$y_{\text{loss}} = \gamma_{\text{veg}}(\text{CWI}) \cdot d_{\text{chord}}$$
3. **GNSS-R Multipath Interferometric Notch Frequency:**
   $$f_{\text{notch}} = \frac{2 h_{\text{ant}}}{\lambda} \sin\theta_{\text{elev}}$$

### Step 2: Separate Observed Measurement Vector from Likelihood Score
In `services/agribrain/mesia/contracts/behaviour.py`:
- Refactor `BehaviourLikelihood`:
  ```python
  @dataclass(frozen=True)
  class BehaviourLikelihood:
      likelihood_id: str
      target_variable: str               # e.g., "root_zone_water", "canopy_water"
      estimated_physical_value: float   # Calibrated estimate in target physical units (e.g. 0.22 m3/m3)
      observed_raw_metric: float        # Native RF metric (e.g. -14.2 dB, 24.5 dB SNR)
      raw_unit: str                     # "dB", "dBm", "Hz"
      confidence_weight: float          # [0.0, 1.0] statistical quality weight
      covariance: float                 # Metrological variance in target units
      authority_scope: str = "evidence_proposal"
  ```
