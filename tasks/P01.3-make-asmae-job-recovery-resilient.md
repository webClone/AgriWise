## 2. Technical Analysis & Code Audit

### 2.1 Missing `COMPLETED_REINTEGRATION_PENDING` in Recovery Query
In `layer05_asmae/background_jobs.py` line 2265:
```python
candidate_states = [JobStatus.QUEUED, JobStatus.RUNNING, JobStatus.STALLED]
pending_jobs = store.get_jobs_by_states(candidate_states)
```
When worker nodes restart, jobs that successfully computed heavy Bayesian satellite/radar matrix inversions but had not yet completed atomic worldline commit (`COMPLETED_REINTEGRATION_PENDING`) are completely ignored. They remain stranded forever, forcing redundant multi-minute recomputation.

### 2.2 NameError in `_supersede_and_requeue_job`
In `layer05_asmae/background_jobs.py` lines 1264–1271:
```python
def _supersede_and_requeue_job(store, job_id: str) -> tuple[bool, Any]:
    ...
    superseded = store.mark_superseded(job_id)
    ...
    return True, resumed  # <-- NameError: 'resumed' is not defined! Should be 'superseded'
```
Hitting this branch immediately terminates the recovery process with an unhandled exception.

## 3. Implementation Plan

### Step 1: Expand Recovery State Set
In `services/agribrain/layer05_asmae/background_jobs.py`:
```python
candidate_states = [
    JobStatus.QUEUED,
    JobStatus.RUNNING,
    JobStatus.STALLED,
    JobStatus.COMPLETED_REINTEGRATION_PENDING, # <-- Include 2-phase commit recovery
]
```

### Step 2: Fix Undefined Return Variable in Requeue Helper
In `services/agribrain/layer05_asmae/background_jobs.py` line 1271:
```python
return True, superseded
```

### Step 3: Enforce Lease Expiry Validation Before Re-execution
Before preempting a `RUNNING` or `COMPLETED_REINTEGRATION_PENDING` job, verify that its worker lease has strictly expired:
```python
if job.status in (JobStatus.RUNNING, JobStatus.COMPLETED_REINTEGRATION_PENDING):
    if job.lease_expires_at and job.lease_expires_at > datetime.now(timezone.utc):
        continue  # Active worker is still legitimately executing
```
