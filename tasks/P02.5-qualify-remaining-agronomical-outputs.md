## 2. Technical Analysis & Current Deficiencies

### The Heuristic Assumption Gap
Across several agronomical engines, heuristic rules and uncalibrated empirical coefficients are published to farmers as authoritative state:
1. **Layer 6 Yield (`layer6_yield/`):**
   Exists as a separate legacy module disconnected from the main `layer6_exec` runner. It uses fixed empirical yield formulas ($Y = \text{NDVI} \times \text{coeff}$) without validation across cultivars or climate zones.
2. **Layer 5 Biotic Risk (`layer5_biotic_risk/`):**
   Uses spore-load diffusion heuristics and disease susceptibility scores without documented calibration against field scouting or plant pathology traps.
3. **Layer 7 Economic Scenarios:**
   Calculates net margin and ROI using hardcoded seed/commodity prices, assuming a fixed operational plan.
4. **Undefined Abstention:**
   When evaluated on unsupported specialty crops (e.g. coffee, vineyard, berries) or unusual soils (e.g. peat, saline sodic), engines emit confident numerical estimates rather than declaring out-of-domain abstention.

## 3. Implementation Plan

### Step 1: Inventory Equations, Parameters, and Calibrated Crop Domains
Create an agronomical registry in `services/agribrain/scientific_contracts/crop_governance.py`:
```python
@dataclass(frozen=True)
class CropDomainQualification:
    crop_name: str
    botanical_family: str
    supported_soil_textures: List[str]
    calibrated_phenology_models: List[str]  # e.g. ["GDD_WHEAT_ZADOKS", "GDD_MAIZE_BBCH"]
    max_allowable_depletion_p: float
    base_temperature_c: float
    nitrogen_uptake_curve_type: str
    is_yield_calibrated: bool
    is_disease_model_calibrated: bool
```
Explicitly declare the **Tier 1 Supported Crops**:
- `POTATO` (Solanum tuberosum)
- `WHEAT` (Triticum aestivum)
- `MAIZE` (Zea mays)
All other crops must default to `TIER_2_GENERIC_SCENARIO` with an explicit notice:
`"Crop parameters are generic estimates; species-specific yield and disease models are uncalibrated."`

### Step 2: Implement Domain Boundary Abstention
In Layer 2, Layer 4, and Layer 5 runners:
- Check if `crop_type` is supported in the plot region.
- If out-of-domain (e.g. Vineyard evaluated against annual cereal model):
  - Do not emit fabricated disease or nutrient deficit numbers.
  - Set `status = LayerStatus.DEGRADED`.
  - Record `missing_drivers.append("UNSUPPORTED_CROP_DOMAIN")`.

### Step 3: Resolve Status of `layer6_yield`
- Officially classify `services/agribrain/layer6_yield/` as an **Experimental Module**.
- Remove it from production execution profiles until field-calibration trials against harvest weigh-wagon data are recorded.
