## 2. Technical Analysis & Current Deficiencies

### The Absence of Frozen Evidence Datasets
Currently, running tests or executing the orchestrator frequently fetches live weather APIs, accesses external database connections, or relies on mock objects that do not represent realistic multi-spectral satellite rasters or soil matrices.
Without frozen, immutable evidence bundles:
1. Performance regressions and numerical drift cannot be isolated from API changes.
2. Direct execution probes in different environments yield diverging outcomes.
3. Edge cases (cloud gaps, sensor dropouts, missing weather) cannot be verified repeatably.

---

## 3. Implementation Plan

### Step 1: Create Seven Canonical Frozen Evidence Bundles
In `golden/bundles/`, create serialized, self-contained JSON/binary datasets:
1. **Bundle 01 — Data-Rich Golden Plot (`bundle_01_data_rich`):**
   - 180-day complete Sentinel-2 L2A optical + Sentinel-1 GRD SAR backscatter.
   - Hourly weather (ERA5 / ECMWF) with realistic diurnal curves.
   - Multi-depth soil capacitance probe time series ($10\text{cm}, 30\text{cm}, 60\text{cm}$).
   - Complete soil texture lab assay (Sandy Loam: 65% sand, 15% clay, 20% silt).
2. **Bundle 02 — Sparse Satellite Only (`bundle_02_sparse`):**
   - Only 2 cloud-free optical scenes over 60 days, no SAR, no in-situ probe.
   - Evaluates prior-based propagation and uncertainty expansion.
3. **Bundle 03 — Missing Weather Outage (`bundle_03_missing_weather`):**
   - Complete satellite coverage, but weather API timeseries contains 10 consecutive missing days (`et0=None, precip=None`).
   - Evaluates fail-closed degradation (Task A03).
4. **Bundle 04 — Corrupt / Failed External Scene (`bundle_04_corrupt_scene`):**
   - High-resolution drone orthomosaic with malformed affine transform or unprojected CRS.
   - Evaluates explicit admission rejection receipts (Task A06).
5. **Bundle 05 — Irregular Temporal Sampling (`bundle_05_irregular_time`):**
   - Observations sampled at intervals of 1, 3, 18, 2, and 25 days.
   - Evaluates calendar-day derivative scaling (Tasks A17 & A18).
6. **Bundle 06 — Interrupted ASMAE Background Job (`bundle_06_interrupted_job`):**
   - Background job state snapshot paused at `COMPLETED_REINTEGRATION_PENDING` with expired worker lease.
   - Evaluates recovery engine convergence (Task A07).
7. **Bundle 07 — Research-Only MESIA Packet (`bundle_07_research_mesia`):**
   - Uncalibrated Wi-Fi/LoRa RF signal departure packets without validation certificate.
   - Evaluates scientific containment and state update blocking (Tasks A08–A10).

### Step 2: Establish Operational Resource Budgets
Define strict runtime and memory thresholds for production workloads:
| Workload Metric | Target Limit | Enforcement Action |
|:---|:---|:---|
| Plot Max Area | $500\text{ ha}$ | Reject or partition into sub-fields |
| Observation Window | $365\text{ days}$ | Truncate history beyond 1 crop cycle |
| L1–L6 Execution Latency | $\le 4.5\text{ seconds}$ | Alert and emit performance log |
| Memory Footprint (Per Run) | $\le 1.2\text{ GB RAM}$ | Stream rasters via windowed chunking |
| ASMAE Job Timeout | $300\text{ seconds}$ | Mark STALLED and release lease |
