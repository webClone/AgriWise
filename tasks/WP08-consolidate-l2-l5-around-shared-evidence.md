# Work Package 08: Consolidate L2–L5 Around Shared Evidence

## 1. Executive Summary & Objective
The diagnostic layers (L2 Intelligence, L3 Water/Decision, L4 Nutrients, L5 Bio Threat) contain advanced domain engines, but their interfaces suffer from severe evidence-sharing defects:
1. **Manufactured L2 Hypotheses (Finding #23)**: In `composite_runner.py`, `H_distribution` is generated by summing stress *severities* and adding a constant $1.0$ for unresolved stress. This conflates severity with probability.
2. **Disconnected Authoritative Water Engine (Finding #27)**: The sophisticated hydrological simulation engine in `services/agribrain/layer3_water/` is completely disconnected from the orchestrator's production L3 path, while its internal uncertainty calculation improperly applies a variance reduction directly to standard deviation and fails to pass the posterior sigma to downstream forecast modules.
3. **Dropped Inputs & Fake Completeness in L4 (Findings #28, #29)**: The orchestrator wrapper drops critical inputs supported by L4's standalone engine (irrigation events, crop parameters, cover crops), while substituting an arbitrary $0.5$ NDVI default that downstream quality checks interpret as real observational completeness.
4. **Double-Counting in L5 (Finding #30)**: L5 weed-pressure inference combines satellite EO indicators with an inherited L3 weed diagnosis, counting the same underlying observations twice.

Work Package 08 consolidates Layers 2 through 5 around a shared canonical evidence model, connecting the authoritative water expert, fixing uncertainty math, and preserving true observational missingness.

## 3. Root Cause & Architectural Breakdown

### 3.1 Severity vs Probability Simplex in L2 (Finding #23)
In `layer2_intelligence/composite_runner.py`:
```python
for stress in output.stress_context:
    by_type[key] = by_type.get(key, 0.0) + max(0.0, float(getattr(stress, "severity", 0.0) or 0.0))
unresolved_weight = 1.0 + by_type.pop("UNRESOLVED", 0.0)
total = sum(by_type.values()) + unresolved_weight
hypotheses = {key: value / total for key, value in sorted(by_type.items())}
hypotheses["UNRESOLVED"] = unresolved_weight / total
```
A severe nitrogen deficiency ($0.9$ severity) supported by weak evidence is assigned $3\times$ higher probability than a mild water deficit ($0.3$ severity) verified by multiple in-situ sensors. Furthermore, forcing all stresses into a single simplex assumes stresses are mutually exclusive: in reality, water deficit and nitrogen deficiency routinely coexist.

### 3.2 L3 Water Engine Disconnection & Uncertainty Propagation (Finding #27)
1. In production, the orchestrator invokes `layer3_decision.runner.run_layer3_decision`, completely bypassing `services/agribrain/layer3_water/runner.py`. The richer FAO-56 dual-Kc, root-zone availability, and MPC irrigation engine sits dormant.
2. Inside `layer3_water/runner.py`:
   ```python
   _posterior_soil_sigma = max(0.01, round(
       et0_res.uncertainty.soil_sigma * (1.0 - assim_diag.variance_reduction_fraction), 4
   ))
   ...
   lim_forecast = EnsembleForecastEngine.simulate_depletion_forecast(
       ...,
       soil_uncertainty_sigma=et0_res.uncertainty.soil_sigma,  # BUG: passes prior sigma!
   )
   ```
   `variance_reduction_fraction` is $1 - \text{Trace}(P^+) / \text{Trace}(P^-)$. Standard deviation scales with the square root: $\sigma_{\text{post}} = \sigma_{\text{prior}} \times \sqrt{1 - \text{fraction}}$. Moreover, line 248 ignores `_posterior_soil_sigma` and passes the prior `soil_sigma`.

### 3.3 Dropped Arguments & Fake Completeness in L4 (Findings #28, #29)
In `layer4_nutrients/runner.py`:
- Line 887: `if ndvi is None: ndvi = 0.5`. When satellite imagery is cloudy or unavailable, L4 fabricates an NDVI of $0.5$. Downstream completeness metrics check `if ndvi > 0: spectral_completeness = 1.0`, disguising missing data as perfect observation.
- Line 862: Takes the first observed NDVI sample in the time-series array rather than sorting chronologically to find the latest valid sample before the cutoff.
- Lines 1056-1080: `run_layer4_standalone` supports `irrigation_events`, `crop_params`, `soil_moisture`, and tissue tests, but the orchestrator wrapper passes `None` or omits them entirely.

## 4. Implementation Specification

### 4.1 Step 1: Reform L2 Hypothesis Attribution
1. Publish true posterior probabilities derived directly from the Bayesian attribution engine (`attribution/inference.py`), separating probability $P(H | E)$, severity $S \in [0, 1]$, and confidence $C \in [0, 1]$.
2. Model stress hypotheses as independent Bernoulli distributions (allowing coexisting stresses) rather than forcing them into a mutually exclusive categorical simplex.

### 4.2 Step 2: Connect Authoritative Water Expert & Fix Uncertainty
1. Integrate `services/agribrain/layer3_water/` as the authoritative water expert inside the canonical L3 decision flow.
2. Correct the posterior standard deviation formula:
   ```python
   _posterior_soil_sigma = max(0.005, round(
       et0_res.uncertainty.soil_sigma * math.sqrt(max(0.05, 1.0 - assim_diag.variance_reduction_fraction)),
       4
   ))
   ```
3. Pass `soil_uncertainty_sigma=_posterior_soil_sigma` into `EnsembleForecastEngine.simulate_depletion_forecast`.

### 4.3 Step 3: Implement Typed NutrientInput Adapter in L4
1. Define `NutrientInputContext` mapping all available upstream data:
   - Pass confirmed `irrigation_events` from Layer 0.5/L3.
   - Pass root-zone moisture from ASMAE.
   - Sort timeseries chronologically and select the latest observed sample strictly before `knowledge_cutoff`.
2. Forbid synthetic NDVI substitution: if NDVI is missing, set `ndvi = None`. Tag `spectral_completeness = 0.0` and increase prior epistemic uncertainty in the Bayesian nutrient inference engine.

### 4.4 Step 4: Disentangle Evidence Lineage in L5 Bio Threat
1. In `layer5_bio/engines/inference.py`, track evidence lineage IDs. If an inherited L3 diagnosis shares the same underlying Sentinel-2 scene as L5's canopy moisture indicator, pass their joint covariance or condition on the shared evidence once, preventing artificial certainty inflation.
