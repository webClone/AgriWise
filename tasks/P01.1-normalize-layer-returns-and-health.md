## 2. Technical Analysis & Current Deficiencies

### 2.1 Double-Envelope Nesting in Layer 7 Planning
In `layer7_planning/runner.py`, the return statement wraps an already-formed `LayerResult` inside another `LayerResult`:
```python
# layer7_planning/runner.py
return LayerResult(
    layer_id=LayerId.L7,
    status=LayerStatus.OK,
    output=LayerResult(...) # <-- Double nesting!
)
```
Downstream consumers and `orchestrator_v2/gating.py` attempting to access `l7_res.output.crop_plan` or `l7_res.output.rotations` encounter unexpected dict nesting or attribute errors, requiring ad-hoc unwrap heuristics.

### 2.2 Global Quality Metrics & Health Blindness
In `orchestrator_v2/runner.py`:
- `quality_metrics` (e.g. cloud cover fraction, spatial coverage, epistemic uncertainty, sensor age) are computed per layer but discarded from the top-level pipeline return.
- The global orchestrator health flag reports `OK` even when 8 of 10 layers degraded to synthetic priors or uncalibrated fallback defaults.
- No unified composite health index ($Q_{\text{pipeline}} \in [0, 1]$) is emitted to API clients.

## 3. Implementation Plan

### Step 1: Flatten Layer 7 Planning Return Contract
In `services/agribrain/layer7_planning/runner.py`:
- Remove redundant outer `LayerResult` construction.
- Ensure `run_layer7_planning` returns a single, canonical `LayerResult(layer_id=LayerId.L7, status=status, output=planning_output)`.
- Update `services/agribrain/layer7_planning/tests/` to verify flattened contract.

### Step 2: Implement Pipeline Composite Quality Index ($Q_{\text{pipeline}}$)
In `services/agribrain/orchestrator_v2/gating.py`:
- Define mathematical quality aggregation across executed layers:
  $$Q_{\text{pipeline}} = \sum_{i \in \text{Executed}} w_i \cdot q_i \cdot \mathbb{I}(\text{status}_i == \text{OK})$$
- Where $w_i$ is layer criticality weight ($\sum w_i = 1.0$), and $q_i \in [0, 1]$ is layer internal confidence.
- Expose `quality_metrics` directly in `OrchestrationResult`:
  ```python
  @dataclass(frozen=True)
  class PipelineQualitySummary:
      composite_score: float  # [0.0, 1.0]
      degraded_layers: List[str]
      uncalibrated_layers: List[str]
      optical_cloud_cover_pct: float
      radio_evidence_available: bool
  ```

### Step 3: Enforce Execution Profile Boundary Gating
In `services/agribrain/orchestrator_v2/runner.py`:
- Validate that only layers belonging to the requested `ExecutionProfile` are evaluated for health.
- Skipped layers corresponding to unrequested profiles must be marked `SKIPPED_BY_PROFILE` rather than `FAILED` or `MISSING`.
