## 2. Technical Analysis & Current Deficiencies

### 2.1 Spontaneous Water Generation at Wilting Point
In `layered_water_balance.py` line 122:
```python
new_storage[i] = max(wp_storage_mm[i], new_storage[i] - actual_layer_uptake)
```
If a dry layer begins below wilting point (e.g. at residual storage $39\text{ mm}$ with wilting point $67.5\text{ mm}$), `max()` clamps storage to $67.5\text{ mm}$. This manufactures $+28.5\text{ mm}$ of phantom water per layer out of nothing!

### 2.2 Inconsistent Mass Closure Equation
In lines 137–147, `total_plant_extracted` in the mass balance equation is evaluated against pre-infiltration storage `layer_storage_mm[i]` rather than post-infiltration storage `new_storage[i]`, causing false mass balance alarms during rainfall events.

### 2.3 Dropped Posterior Uncertainty & Stale Forecast Sigma
In `layer3_water/runner.py`:
1. Formula $\sigma_{\text{post}} = \sigma_{\text{prior}} (1 - f)$ is dimensionally incorrect (variance scales as $(1-f)$, standard deviation scales as $\sqrt{1-f}$).
2. `_posterior_soil_sigma` is calculated but then discarded; the downstream ensemble depletion forecast (line 248) and canonical output (line 287) consume stale prior sigma `et0_res.uncertainty.soil_sigma`.

## 3. Implementation Plan

### Step 1: Enforce Strict Non-Negative Extraction Without Clamping
In `services/agribrain/layer3_water/soil/layered_water_balance.py`:
```python
for i in range(n_layers):
    if i < len(uptake_fractions):
        target_uptake = round(uptake_fractions[i] * actual_transpiration_mm, 2)
        # Plant can only extract water above wilting point, but if already below WP, extract 0.0
        extractable = max(0.0, new_storage[i] - wp_storage_mm[i])
        actual_layer_uptake = min(target_uptake, extractable)
        new_storage[i] = new_storage[i] - actual_layer_uptake  # Do NOT clamp with max(wp)
        layer_uptake_actual.append(actual_layer_uptake)
```

### Step 2: Harmonize Mass Balance Ledger
Use identical extracted amounts in both the layer state update and the mass balance verification:
```python
total_plant_extracted = sum(layer_uptake_actual)
outflows = total_plant_extracted + actual_top_evap + deep_drainage
delta_s = sum(new_storage) - sum(layer_storage_mm)
mass_balance_error = round(abs(delta_s - (inflows - outflows)), 4)
assert mass_balance_error < 1e-3, f"Mass balance violation: error={mass_balance_error} mm"
```

### Step 3: Propagate Calibrated Posterior Sigma
In `services/agribrain/layer3_water/runner.py`:
```python
# Standard deviation scales as square root of variance reduction
posterior_sigma = max(0.01, round(
    et0_res.uncertainty.soil_sigma * math.sqrt(max(0.0, 1.0 - assim_diag.variance_reduction_fraction)),
    4,
))
# Feed posterior_sigma into ensemble forecast and canonical output
lim_forecast = EnsembleForecastEngine.simulate_depletion_forecast(
    ...
    soil_uncertainty_sigma=posterior_sigma,
)
```
