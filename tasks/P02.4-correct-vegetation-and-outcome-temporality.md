## 2. Technical Analysis & Current Deficiencies

### 2.1 Missing `statistics` Import in Layer 2 Growth Engine
In `layer2_veg_int/growth_engine.py`:
- Functions calling `statistics.mean()` or `statistics.stdev()` crash with `NameError: name 'statistics' is not defined` because the module import is missing.
- Time differentials between NDVI observations assume a uniform $\Delta t = 5\text{ days}$, introducing large vegetative derivative errors when cloud-masked intervals span 15–25 days.

### 2.2 Layer 6 Outcome Evaluation Without Explicit Causal Lag
In `layer6_exec/outcomes/metrics.py`:
- Prescription outcome evaluation assesses crop response immediately on the day following fertilizer application ($t + 1\text{ day}$).
- Agronomical reality: Granular nitrogen and phosphorus require soil dissolution, microbial nitrification, and root uptake, exhibiting an obligatory physiological lag of $7 - 14\text{ days}$. Evaluating biomass delta at $t+1$ attributes unrelated weather shocks to the prescription.

## 3. Implementation Plan

### Step 1: Fix Missing Import & Real Geodetic Observation Time Spacing
In `services/agribrain/layer2_veg_int/growth_engine.py`:
- Add `import statistics`.
- Calculate true elapsed days $\Delta t = (t_k - t_{k-1}).\text{days}$ between valid cloud-free acquisitions:
  $$\frac{d\text{NDVI}}{dt} \approx \frac{\text{NDVI}_k - \text{NDVI}_{k-1}}{\Delta t}$$

### Step 2: Enforce Action-Specific Physiological Response Windows
In `services/agribrain/layer6_exec/outcomes/metrics.py`:
Define canonical evaluation response horizons per action type:
| Action Category | Mandatory Evaluation Horizon | Physiological Mechanism |
|---|---|---|
| **Foliar Micronutrient Spray** | $3 - 7\text{ days}$ | Direct stomatal/cuticular foliar absorption |
| **Granular Nitrogen Top-Dress** | $10 - 21\text{ days}$ | Dissolution, nitrification & root-zone uptake |
| **Drip Irrigation Pulse** | $1 - 3\text{ days}$ | Immediate hydraulic potential recovery |
| **Pre-Planting Basal Fertilizer**| $30 - 60\text{ days}$ | Early vegetative vigor development |
