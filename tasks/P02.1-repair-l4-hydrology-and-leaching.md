## 2. Technical Analysis & Current Deficiencies

### 2.1 Catastrophic Rainfall Discontinuity at 250mm
In `layer4_nutrients/soil_water_balance/engine.py` lines 261–266:
```python
if rain <= 0:
    p_eff = 0.0
elif rain < 250:
    p_eff = rain * (125.0 - 0.2 * rain) / 125.0
else:
    p_eff = rain * 0.1 + 25.0
```
- At $\text{rain} = 249.9\text{ mm}$, $P_{\text{eff}} \approx 149.98\text{ mm}$.
- At $\text{rain} = 250.0\text{ mm}$, $P_{\text{eff}} = 50.00\text{ mm}$.
- A $0.1\text{ mm}$ rain increment produces an instant drop of **$100\text{ mm}$** of water, causing flood events to falsely trigger drought alerts!

### 2.2 Factor-of-10 Nitrogen Leaching Mass Error
In `layer4_nutrients/soil_water_balance/engine.py` line 317:
```python
n_leaching = total_deep_perc * no3_conc_mg_l / 1000.0  # mm * mg/L → kg/ha
```
- $1\text{ mm} \times 1\text{ ha} = 10,000\text{ L}$.
- $10,000\text{ L} \times 1\text{ mg/L} = 10,000\text{ mg} = 0.01\text{ kg}$.
- The factor must be **$0.01$** (dividing by $100.0$), NOT dividing by $1000.0$. The current formula underreports nitrogen loss by **$10\times$**, leading to dangerous fertilizer under-replenishment.

### 2.3 Missing Weather Rows Treated as 0.0 Stress
In lines 217–224:
```python
if et0 is None or rain is None:
    daily_stress.append(0.0)
    daily_leaching.append(0.0)
    continue
```
Missing sensor data is recorded as zero water stress, causing the system to advise high doses of dry nitrogen fertilizer during unmonitored drought periods.

## 3. Implementation Plan

### Step 1: Replace Piecewise Precipitation with Smooth USDA-SCS Daily Curve
In `services/agribrain/layer4_nutrients/soil_water_balance/engine.py`:
```python
# USDA-SCS / FAO continuous daily effective precipitation
if rain <= 0.0:
    p_eff = 0.0
elif rain <= 8.0:
    # Interception threshold: light rain evaporates before infiltrating
    p_eff = 0.0
else:
    # Smooth exponential retention curve
    p_eff = max(0.0, 0.8 * rain - 5.0) if rain <= 70.0 else max(0.0, 0.95 * rain - 15.0)
```

### Step 2: Correct Nitrogen Leaching Dimension
In line 317:
```python
# Dimensional derivation: 1 mm * 1 ha = 10,000 L. 10,000 L * C mg/L = 10,000 * C mg = 0.01 * C kg.
# Nitrate-N conversion: if no3_conc_mg_l is elemental N:
n_leaching_kg_ha = total_deep_perc * no3_conc_mg_l * 0.01
```

### Step 3: Explicit Missing Weather Accounting
In `services/agribrain/layer4_nutrients/soil_water_balance/engine.py`:
- Track `missing_weather_days`.
- If missing days exceed 20% of the window, mark `water_stress_status = "INDETERMINATE_MISSING_WEATHER"` and inflate confidence intervals.
- Do NOT append `0.0` to `daily_stress`. Propagate previous day's stress with decay or conservative estimate.
