## 2. Technical Analysis & Current Deficiencies

### 2.1 Regex-Only Hallucination Guard
In `layer9_interface/hallucination_guard.py`:
- The hallucination guard verifies generated natural language explanations using shallow regex pattern matching (e.g. checking if numbers like "25 kg/ha" appear in the prompt text).
- *The Vulnerability:* Semantic inversions pass unchecked:
  - If Layer 4 computed an *excess* of nitrogen, but the LLM stated *"Apply 50 kg/ha nitrogen because soil is severely deficient"*, the regex sees "50 kg/ha" and validates the response as grounded!
  - Causal directions (e.g., attributing soil drying to leaf transpiration vs evaporation) are not verified against actual layer state vectors.

## 3. Implementation Plan

### Step 1: Implement Propositional Claim Extraction
In `services/agribrain/layer9_interface/hallucination_guard.py`:
- Decompose generated natural language advisory into atomic verifiable claims:
  1. **Numerical assertions:** Target rates, thresholds, dates.
  2. **Directional assertions:** Increase, decrease, stable, deficient, surplus.
  3. **Causal assertions:** Attributed stress factors (water deficit, nitrogen deficiency, sirocco wind, fungal infection).

### Step 2: Strict State Vector Corroboration
For each extracted claim:
- Corroborate against canonical upstream receipts:
  - Water claims $\to$ `HydrologyStateReceipt` (L3 Water).
  - Nutrient claims $\to$ `NutrientBudgetReceipt` (L4 Nutrients).
  - Disease claims $\to$ `PathologyRiskReceipt` (L5 Biological Risk).
  - Prescriptions $\to$ `ActionCard` list (L8 Prescriptions).
- If any directional claim contradicts the upstream layer receipt, **FAIL CLOSED**:
  - Quarantine the generated text.
  - Fall back to deterministic template-generated explanation.
